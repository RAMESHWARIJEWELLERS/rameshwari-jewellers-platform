4 · Canonical architecture statement

Rameshwari Jewellers uses an Elementor Free-first integration architecture. Elementor Free/Core is the compatibility baseline. Elementor Pro may enhance presentation capabilities but is never a dependency for core business functionality. RJ Plugin owns business data and business logic. Shared renderers and services are exposed through native builder capabilities, shortcodes, theme components and RJ Free-compatible widgets as appropriate. Optional Pro dynamic tags and advanced features sit above this baseline.

Present verbatim in the Final Specification Lock Part 5. Development Blueprint §12 and Technical Blueprint §5.2 now state the same precedence in their own words, so a developer reading either arrives at the same rule.
